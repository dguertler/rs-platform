# Assets

Lege hier dein **eigenes** Marken-Logo ab:

```
instagram/assets/logo.png
```

- PNG mit transparentem Hintergrund, möglichst quadratisch oder hoch.
- Wird automatisch oben links im Header jeder Slide eingeblendet
  (Höhe ~64 px, Breite proportional). Fehlt die Datei, erscheint nur die
  Wortmarke „AI ALPHA SELECTIONS".

⚠️ **Nicht** das wikifolio-Logo verwenden — das ist nur mit vorheriger
schriftlicher Freigabe durch wikifolio erlaubt. Dein eigenes Logo
(z. B. über Claude erstellt) ist frei nutzbar.

## Logo bereitstellen

- **Per Git:** Datei hier ablegen, committen, pushen.
- **Im Chat:** Bild anhängen/hochladen und Claude bitten, es als
  `instagram/assets/logo.png` zu speichern.
